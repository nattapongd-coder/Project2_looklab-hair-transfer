# การแบ่งชุดข้อมูล (Dataset Split v2)

ไฟล์ในโฟลเดอร์นี้บอกว่าภาพแต่ละภาพอยู่ชุดไหน **ไม่มีภาพจริง** และตัดชื่อไฟล์ต้นฉบับออกแล้วเพื่อความเป็นส่วนตัว

| ไฟล์ | เนื้อหา |
|---|---|
| `train.json` | ชุดฝึก — ใบหน้า 39 / ทรงผม 21 / สีผม 21 ภาพ (จับคู่เป็น 150 ชุดในโน้ตบุ๊กฝึก) |
| `validation.json` | ชุดตรวจสอบ — ใบหน้า 9 / ทรง 5 / สี 5 (9 ชุด) ใช้เลือก checkpoint |
| `test_candidate.json` | ชุดทดสอบ — ใบหน้า 10 / ทรง 5 / สี 5 (10 ชุด) ใช้วัดผลสุดท้ายเท่านั้น |
| `review_only.json` | 2 ภาพที่แยกไว้ไม่ใช้ (ความละเอียดต่ำ / ต้องตรวจต้นฉบับ) |
| `manifest.json` | รายการทั้งหมด 122 ภาพ พร้อมขนาดภาพ และ sha256 |

## หลักการแบ่ง

- รหัส `person_XXX` คือกลุ่มบุคคล รูปของคนเดียวกันจะอยู่ชุดเดียวกันเสมอ ไม่ข้ามระหว่าง train / validation / test
- รหัส `template_*` คือกลุ่มภาพอ้างอิงทรง/สีที่มีองค์ประกอบคล้ายกัน เก็บไว้ชุดเดียวกันทั้งกลุ่ม
- แยกสีธรรมชาติ/สีสด และทรงสั้น/กลาง/ยาว/หยิก/หน้าม้า ให้กระจายในแต่ละชุด
- ชุดทดสอบไม่ถูกใช้ปรับ loss หรือเลือก checkpoint

## ใช้กับชุดข้อมูลของตัวเอง

จัดโฟลเดอร์ภาพเป็น `train/{faces,styles,colors}`, `validation/...`, `test_candidate/...` ตามช่อง `file`
แล้วเปลี่ยน path ของชุดข้อมูลในโน้ตบุ๊ก `finetune/` ให้ชี้ไปที่โฟลเดอร์นั้น
